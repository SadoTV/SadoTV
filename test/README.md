# SadoTV test playlist

A small playlist for testing SadoTV (for example during app store review). It contains **only public
test streams published by streaming companies for developers (Amazon, Apple, Google, Mux, Unified
Streaming), and open-licence films and a series** from the Blender Foundation under Creative Commons
Attribution. SadoTV itself does not include or sell any content.

**Playlist URL (M3U):** `https://raw.githubusercontent.com/SadoTV/SadoTV/main/test/sadotv-test.m3u`

In SadoTV: *Add playlist → M3U URL →* paste the address above *→ Add this playlist*.
